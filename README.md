# Cloud Native DevSecOps Platform (Terraform)

## 📌 Project Overview
This project provisions an AWS S3 bucket using Terraform as part of a Cloud Native DevSecOps learning journey.

## 🛠️ Tech Stack
- Terraform
- AWS (S3)
- Ubuntu Linux
- GitHub

## 📂 Resources Created
- AWS S3 Bucket
- Bucket Versioning
- Server-side Encryption
- Object Lock Configuration
